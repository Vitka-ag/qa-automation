# Лабораторна робота № 1 — Автоматизація тестування

## Мета роботи

Налаштувати середовище автоматизованого тестування на TypeScript із використанням Vitest, ESLint, Prettier та перевірки покриття коду тестами.

## Варіант № 1

Реалізація конвертації відстані з кілометрів у милі та з миль у кілометри.

Передбачено перевірку коректних значень, нульової відстані та обробку від'ємних значень.

## Технології

- Node.js
- TypeScript
- Vitest
- ESLint
- Prettier
- Git

## Структура проєкту

- `src/distance.ts` — функції конвертації відстані.
- `tests/distance.test.ts` — тести для варіанта № 1.
- `src/temperature.ts` — додатковий приклад функції.
- `tests/temperature.test.ts` — тести додаткового прикладу.
- `vitest.config.ts` — налаштування тестування та покриття.
- `tsconfig.json` — налаштування TypeScript.
- `eslint.config.mjs` — правила статичного аналізу.
- `.prettierrc` — налаштування форматування.
- `package.json` — залежності та команди проєкту.

## Запуск

Встановлення залежностей:

```bash
npm install
```

Запуск тестів:

```bash
npm test
```

Режим стеження:

```bash
npm run test:watch
```

Перевірка покриття:

```bash
npm run coverage
```

Перевірка ESLint:

```bash
npm run lint
```

Форматування:

```bash
npm run format
```

## Результати

Успішно виконано 9 тестів. Покриття коду становить 100% за показниками Statements, Branches, Functions і Lines.

# Лабораторна робота №2 — Модульне тестування бізнес-логіки

## Тема роботи

Модульне тестування бізнес-логіки засобами Vitest. Матчери, параметризовані тести, покриття коду.

## Мета роботи

Навчитися розробляти модульні тести для функцій бізнес-логіки з використанням Vitest, застосовувати матчери, параметризовані тести, перевіряти граничні значення та виняткові ситуації, аналізувати покриття коду.

## Реалізована функціональність

У файлі `src/order.ts` реалізовано функції:

- `calcSubtotal` — обчислення вартості товарів.
- `calcDiscountRate` — визначення знижки залежно від рівня клієнта та суми замовлення.
- `calcShipping` — обчислення вартості доставки.
- `calcOrderTotal` — визначення остаточної суми замовлення.
- `applyLoyaltyPoints` — списання бонусних балів за індивідуальним варіантом №1.

## Індивідуальне завдання — варіант №1

Реалізовано функцію `applyLoyaltyPoints(total, points)`.

Один бонусний бал дорівнює одній гривні. Максимальна кількість бонусів, яку можна списати, становить 30% суми замовлення. Від'ємна кількість бонусів викликає виняток.

## Автоматизоване тестування

Для перевірки бізнес-логіки використано Vitest.

Тести містять перевірки коректних і некоректних даних, граничних значень, винятків та параметризовані сценарії.

Файли тестування:

- `tests/order.test.ts` — 23 тести.
- `tests/loyalty.test.ts` — 14 тестів.
- `tests/distance.test.ts` — 5 тестів.
- `tests/temperature.test.ts` — 4 тести.

Загалом успішно виконано **46 автоматизованих тестів**.

## Запуск перевірок

```bash
npm install
npm test
npm run coverage
npm run lint
npx prettier --check .
```

Усі 46 тестів завершилися успішно.

Покриття інструкцій, гілок, функцій і рядків коду становить 100%.

Перевірки ESLint і Prettier виконані без помилок.

## Висновок

Під час виконання лабораторної роботи було реалізовано та протестовано функції бізнес-логіки замовлення. Використано параметризовані тести, перевірки граничних значень і виняткових ситуацій. Досліджено показники покриття коду та встановлено, що високе покриття саме по собі не гарантує якості тестування.
